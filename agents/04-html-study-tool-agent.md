# Agent 4 — HTML Study Tool Agent

## Purpose
Convert the interview preparation guide into an interactive, self-contained single-file HTML study tool.

## Prompt used

```
You are a senior frontend developer. Convert the FYUL interview preparation guide (provided as Markdown) into a polished, self-contained single HTML file.

Requirements:
- No external dependencies except Google Fonts (loaded via CDN)
- Dark/light mode toggle
- Progress tracker: shows % of questions reviewed
- Navigation: sticky header with section tabs
- Q&A format: click to reveal answer (flashcard style)
- Communication style cheat sheet: two-column table, visually distinct
- "Questions to ask Marcel" section: organized by topic with expand/collapse
- Design: clean, professional, neutral color palette (greens/teals — Printify brand adjacent)
- Fully responsive (mobile-friendly)
- All content in Spanish

The file must be completely standalone — open it in any browser with no internet required (except Google Fonts).
```
